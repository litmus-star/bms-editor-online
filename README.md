# BMS 웹 에디터 (index.html)

iBMSC를 참고해 만든 7키 SP·DP용 BMS 패턴 편집기. HTML 파일 하나로 동작하며 모든 처리는 이 컴퓨터의 브라우저 안에서만 이루어진다(서버 없음, 외부 통신은 CSP로 차단).

## 쓰는 법
1. `index.html`을 크롬이나 엣지로 연다(더블클릭).
2. **폴더 열기**로 곡 폴더를 고르거나, 폴더를 창에 끌어다 놓는다. 패턴 파일과 키음을 함께 불러온다.
3. 편집한 뒤 **Ctrl+S**를 누른다. 원래 파일에 덮어쓰고, 처음 덮어쓸 때 원본을 `.bak`으로 백업한다.
   - 크롬·엣지가 아닌 브라우저에서는 저장할 때 파일이 다운로드된다.

## 조작
- **선택(F1)**
  - 클릭으로 선택, 빈 곳을 끌어서 범위 선택
  - 노트를 끌어서 이동(BGM ↔ 키 레인 포함), Ctrl+드래그로 복사
  - 롱노트 윗끝을 끌어서 길이 조절, 더블클릭으로 값 바꾸기
- **쓰기(F3)**
  - 클릭하면 WAV 목록에서 고른 키음으로 노트를 찍음
  - 위로 끌면 롱노트
  - 기존 노트를 클릭하면 그 키음을 집어옴
  - BPM/STOP 레인을 클릭하면 값을 입력
- **공통**
  - 오른쪽 클릭: 삭제
  - 가운데 버튼 드래그: 화면을 잡고 끌기(위아래 + BGM 칼럼 가로 스크롤)
  - 툴바의 "옆으로만"(H)이 켜져 있으면 노트를 옮길 때 위아래로 움직이지 않음 (열 때마다 기본으로 켜짐)
  - Shift: 그리드 무시(1/192)
  - 겹치게 옮기면 원래 노트는 빈 BGM 레인으로 비켜남
- **키보드**

  | 키 | 기능 |
  |---|---|
  | Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
  | Ctrl+X / C / V, Ctrl+A | 잘라내기 / 복사 / 붙여넣기, 전체 선택 |
  | ↑↓ | 그리드 한 칸 이동 |
  | ←→ | 레인 이동 |
  | PageUp / PageDown | 한 마디씩 스크롤 |
  | G | 스냅 켜기·끄기 |
  | + / − (Ctrl+휠) | 세로 확대 / 축소 |
  | [ / ] (Ctrl+Shift+휠) | 가로 확대 / 축소 |
  | F5 / F6(Space) / F7 | 처음부터 재생 / 시작선부터 재생 / 정지 |

- **재생**
  - 마디 번호 칸을 클릭하면 재생 시작선이 생긴다.
  - BPM 변화와 STOP을 반영한다.
  - 같은 키음이 다시 울리면 앞 소리는 끊긴다.
  - 중간부터 재생해도 그 전에 시작해서 아직 울리고 있는 키음(긴 BGM 등)은 해당 지점부터 이어서 재생된다.
- **오른쪽 패널**: 패널 왼쪽 경계를 끌면 너비가 바뀌고, 경계의 ▶ 버튼(또는 \ 키)으로 접고 펼친다.
- **가로 스크롤**: 마디~7번 키까지는 고정되고 BGM 칼럼만 스크롤된다.
- **복사·붙여넣기**
  - iBMSC 클립보드 형식이라 iBMSC나 `ibmsc_clip.py` 결과와 서로 붙여넣을 수 있다.
  - 붙여넣는 위치는 마우스가 있는 마디의 시작점 기준이다.

## 태블릿 (손가락 · S펜)

- 손가락: 노트 끌기 = 이동, 빈 곳 끌기 = 화면 이동, 두 손가락 = 확대·축소 (벌리는 방향대로 세로/가로)
- 탭 = 선택 (쓰기 모드는 노트 찍기), 길게 누르기 = 빈 곳은 범위 선택 / 노트는 메뉴 (삭제 · 값 바꾸기 · 복사)
- S펜은 마우스와 같음 (펜 옆 버튼 = 삭제). 펜을 한 번 쓰면 손가락은 화면 이동·확대만 함
- 터치나 펜을 쓰면 아래에 도구 막대가 뜸: ↶ ↷ · ▲▼◀▶ · 복사 · 붙여넣기 · 삭제 · 복사 모드 · 그리드 무시
- 화면 폭이 좁으면 오른쪽 패널은 접힌 채로 시작
- 안드로이드 크롬은 '폴더 직접 접근'으로 열면 키음 900여 개를 읽는 데 3~4분이 걸려서(파일 하나 여는 데 0.2~0.3초, 동시에 열어도 빨라지지 않음), 자동으로 '폴더 고르기' 방식으로 엶(같은 곡 13초). 이 방식은 읽기 전용이라 처음 저장할 때 같은 폴더를 한 번 더 골라 쓰기 권한을 받음. '보기 · 재생 · 저장' 칸에서 바꿀 수 있음

## 저장 방식
- 편집한 부분(BGM·BPM·STOP·1P 키·롱노트·마디 길이·헤더·WAV·확장 블록)의 줄만 다시 쓴다.
- 나머지 줄(BGA, 2P, 숨김 노트, 지뢰, 주석, 모르는 명령)은 원본 바이트 그대로 둔다.
- 마디 길이를 바꾸면 노트·BGA·2P·#RANDOM 블록이 모두 같은 박 위치를 유지하고, 마디선만 움직인다.
- 저장 직전에 결과를 다시 읽어 편집 내용과 일치하는지 확인하고, 바뀐 줄을 보여 준다.
- 기본 인코딩은 Shift-JIS다. 읽을 때 인코딩이 잘못 잡혔으면 아래쪽 인코딩 선택으로 바꿀 수 있다.

## DP · BGA · 숨김 · 지뢰
- `#PLAYER 3`이거나 2P 노트가 있으면 DP 화면으로 연다. 툴바의 SP/DP 버튼으로 바꿀 수 있다(파일 내용은 바뀌지 않음).
- 레인 순서: `마디 | BPM | STOP | 1P SC 1~7 | 2P 1~7 SC | BGA LAYER POOR | B1 B2 …`
- 가로 스크롤하면 플레이 영역은 고정되고 BGA·BGM 영역이 함께 움직인다.
- BGA/LAYER/POOR 레인에는 BMP 목록에서 고른 `#BMPxx` 번호가 찍힌다. BGA 노트는 이 세 레인끼리만 옮겨진다.
- 쓰기 모드에서 툴바의 노트 종류(N 키로 전환)를 숨김·지뢰로 바꾸면 해당 채널(3x/4x, Dx/Ex)로 찍힌다. 지뢰 값은 옆 칸에서 정한다.
- 숨김은 흐린 점선, 지뢰는 ✕ 표시. 둘 다 키 레인 안에서만 옮겨지고 자동 재생 소리는 나지 않는다.
